 Linux File System Hierarchy

/ (Root Directory)

The root directory is the starting point of the Linux file system. Every file and directory exists under this location.

Command Used


ls -l /


What I Observed

Some important directories I found:

- bin
- boot
- dev
- etc
- home
- var

When I would use it

Whenever I need to navigate the complete Linux system.



/home


Command


ls -l /home


Observation

I found the ubuntu users home directory.

When I would use it

To store projects, scripts, and personal files.



/root

This is the home directory of the root user.

Command


ls -l /root



When I would use it

While performing administrative tasks with root privileges.



/etc

This directory contains system configuration files.

Command


ls -l /etc



Some files and directories I noticed:

- hosts
- hostname
- apt
- cron.d
- cloud


Whenever I need to check or modify Linux configuration files.



/var/log

This directory stores log files generated by the operating system and different services.

Commands

bash
ls -l /var/log

du -sh /var/log/* 2>/dev/null | sort -h | tail -5




Some log files I found:

- syslog
- kern.log
- dpkg.log
- journal



Whenever a service or application is not working properly, I would check logs here first.

# Scenario Practice

## Scenario 1 – Service Not Starting


systemctl status myapp

journalctl -u myapp -n 50

systemctl is-enabled myapp

systemctl restart myapp


My Understanding

First check the service status, then review the logs, verify whether it is enabled, and restart the service if needed.


ps aux --sort=-%cpu | head


My Understanding

These commands help identify which process is consuming the most CPU.


 Scenario 3 – Finding Service Logs

 Commands


systemctl status docker

journalctl -u docker -n 50

journalctl -u docker -f


 My Understanding

Service logs help understand why a service failed or behaves unexpectedly.
